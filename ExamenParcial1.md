# 5 tecnologias relacionadas con la ciberseguridad.
## 1. SIEM (Security Information and Event Management) ![imagen SIEM](https://www.cyberseg.solutions/wp-content/uploads/2023/06/siem-cyberseg-2-low.jpg)
## Uso principal: Centralizar y correlacionar logs y eventos de seguridad para detectar anomalias, investigar incidentes y cumplir normativas.
## Vacante real / compañia que la utiliza: Security Operations Center (SOC) Analyst – multiples empresas; p. ej., roles SOC/SIEM en Zscaler, SentinelOne, Okta (empresas que publican vacantes SOC/SIEM).
### enlace de referencia: (infosecjobboard.com)
# 2. EDR / XDR (Endpoint Detection and Response / Extended Detection and Response) ![imagen EDR](https://seguridad.prestigia.es/wp-content/uploads/2021/12/edr-prestigia-seguridad.png)
## Uso principal: Monitoreo continuo de endpoints (laptops, servidores) para detectar, contener y responder a malware, ransomware y comportamientos sospechosos.
## Vacante real / compañia que la utiliza: Threat Detection Engineer, Endpoint Security Engineer – empresas como SentinelOne, CrowdStrike, Microsoft (vacantes relacionadas con EDR/XDR).
### enlace de referencia: (infosecjobboard.com)
# 3. Cloud Security (AWS/Azure/GCP Security) ![cloud security](https://www.kaspersky.es/content/es-es/images/repository/isc/2020/what-is-cloud-security01.jpg)
## Uso principal: Asegurar infraestructura en la nube: redes, identidades, datos, cumplimiento y respuesta a incidentes en entornos cloud. 
## Vacante real / compañia que la utiliza: Cloud Security Engineer – p. ej., Spotify (Cloud Security Engineer), Google (Security Engineer – GCP), AWS/Azure en múltiples ofertas.
### enlace de referencia: (helpnetsecurity.com)
# 4. IAM / MFA (Identity and Access Management / Multi-Factor Authentication) ![Imagen IAM/MFA](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQ4s0YKqMeutjt4_HfaYVmsH9O7ADrLHnbBPtnET0Sd3FK6RcSlUqIFF5A0&s=10)
## Uso principal: Gestionar identidades, accesos y autenticacion fuerte para proteger cuentas y sistemas criticos contra robo de credenciales.
## Vacante real / compañia que la utiliza: Identity Security Engineer, IAM Engineer – empresas como Okta, Zscaler, Cloudflare (vacantes IAM/Identity).
### enlace de referencia: (infosecjobboard.com)
# 5. DevSecOps / AppSec (Application Security) ![imagen DevSecOps](https://www.securitycompass.com/wp-content/uploads/appsec-vs-devsecops.png)
## Uso principal: Integrar seguridad en el ciclo de vida del desarrollo: escaneo de codigo, SAST/DAST, seguridad en CI/CD y respuesta a vulnerabilidades.
## Vacante real/Compañia que lo utiliza: Application Security Engineer, DevSecOps Engineer – p. ej., Anthropic, Stellantis, Cloudflare (vacantes AppSec/DevSecOps).
### enlace de referencia (helpnetsecurity.com)
